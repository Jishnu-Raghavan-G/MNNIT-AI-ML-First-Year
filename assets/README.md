# Assets

This folder contains supporting visual materials used throughout the repository.

## Purpose

The assets in this folder are intended to make machine learning and artificial intelligence concepts easier to understand.

Examples include:

- Diagrams
- Flowcharts
- Algorithm visualizations
- Model architecture diagrams
- Graphs and illustrations
- Images used in the notes

## Examples of Assets

Some assets that may be added while developing the modules include:

- Machine Learning workflow
- Train/Validation/Test split
- Bayes theorem illustration
- KNN distance illustration
- Decision tree structure
- Logistic regression curve
- SVM hyperplane
- K-Means clustering
- Neural network architecture
- Confusion matrix
- BFS and DFS traversal
- A* search
