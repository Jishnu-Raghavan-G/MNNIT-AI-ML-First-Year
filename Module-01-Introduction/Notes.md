# Module 01 — Introduction to Machine Learning

## 1. What is Machine Learning?

Machine Learning (ML) is a subfield of Artificial Intelligence (AI) that focuses on developing algorithms and statistical models that enable computers to perform tasks without being explicitly programmed for every situation.

Machine learning algorithms learn from data to:

- Identify patterns
- Extract useful information
- Make predictions
- Make decisions

Instead of writing rules for every possible situation, we provide data and allow the algorithm to learn patterns from that data.
